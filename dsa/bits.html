Bit manipulation

Every integer is a row of on/off switches. A handful of tricks with AND, OR, XOR and shifts solve problems in O(1) space that would otherwise need a hashmap.

The idea

A row of light switches

A hotel corridor with 8 rooms and a light switch for each. Write "1" for on and "0" for off, and the whole corridor is one number: 00101100. Asking "is room 3's light on?" or "flip room 5" are single operations on that number. File permissions on your laptop (read/write/execute = 4/2/1) work exactly this way.

Patterns

Five bit patterns

1. XOR cancellation

O(n) time · O(1) space

Flipping a light switch twice leaves it where it started. If everyone in a group flips a switch for their name and everyone except one person appears twice, only the loner's switch stays on.

Use wheneverything appears in pairs except one (Single Number), or to find a missing number (XOR indices with values).

def single_number(nums):
    acc = 0
    for x in nums: acc ^= x       # pairs cancel to 0
    return acc

def missing_number(nums):         # 0..n with one missing
    acc = len(nums)
    for i, x in enumerate(nums): acc ^= i ^ x
    return acc

2. Brian Kernighan's bit count

O(number of set bits)

Counting lit rooms by switching off the lowest-numbered lit room each time and counting how many times you did it. You never visit dark rooms.

Use whencounting 1-bits (Number of 1 Bits) or checking powers of two.

def hamming_weight(n):
    count = 0
    while n:
        n &= n - 1          # drops the lowest 1
        count += 1
    return count
n     = 1 0 1 1 0 0
n - 1 = 1 0 1 0 1 1     (borrow flips the lowest 1 and everything below it)
n&n-1 = 1 0 1 0 0 0     → lowest 1 removed

3. DP on bits

O(n)

Counting coins in piggy banks numbered 0 to n: bank i holds the same coins as bank i ÷ 2, plus one more if i is odd. You reuse the answer you already have instead of recounting.

Use whenyou need bit counts for every number 0..n (Counting Bits).

def count_bits(n):
    ans = [0] * (n + 1)
    for i in range(1, n + 1):
        ans[i] = ans[i >> 1] + (i & 1)
    return ans

4. Bitmask as a set

2ⁿ subsets

A pizza order form with checkboxes for 4 toppings. Every possible order is a 4-bit number from 0000 (plain) to 1111 (everything), so looping from 0 to 15 lists every possible pizza.

Use whenn is small (≤ 20) and you need all subsets or a compact "visited set" for DP.

def subsets(nums):
    n = len(nums)
    return [[nums[i] for i in range(n) if mask >> i & 1]
            for mask in range(1 << n)]

5. Adding without +

O(bits)

Adding by hand in school: write the digit sum without carrying (that's XOR), then write the carries one column to the left (that's AND then shift). Repeat until there's nothing left to carry.

Use whenthe problem forbids arithmetic operators (Sum of Two Integers).

def get_sum(a, b):
    MASK = 0xFFFFFFFF                       # simulate 32-bit ints
    while b & MASK:
        a, b = (a ^ b), (a & b) << 1
    a &= MASK
    return a if a <= 0x7FFFFFFF else ~(a ^ MASK)

Python integers have unlimited size, so negative numbers never "overflow" on their own. The mask emulates 32-bit behavior; that's why bit problems feel awkward in Python.

Deep analysis

Single Number II: every number appears three times except one

A school counts votes by tallying each checkbox column separately. If every student except one voted in groups of three identical ballots, each column's tally is a multiple of 3 plus the loner's mark. Taking every column's tally mod 3 reveals the loner's ballot.

XOR alone fails: triples don't cancel (x ^ x ^ x = x).

Count each of the 32 bit positions across all numbers. Mod 3 removes the triples, leaving the single number's bit.

Rebuild the answer from those bits, fixing the sign for 32-bit negatives.

def single_number_ii(nums):
    ans = 0
    for i in range(32):
        bit_sum = sum((x >> i) & 1 for x in nums)
        if bit_sum % 3: ans |= 1 << i
    return ans - (1 << 32) if ans >= 1 << 31 else ans

Complexity: O(32n) = O(n) time, O(1) space.

Bit manipulation shows up less at Google than graphs or trees, but bitmask DP ("n ≤ 16, visit every node") does appear. Recognize the small-n signal.

Before you say "done"

Pitfalls

A light switch panel wired backwards: flipping the wrong one in the wrong order looks fine until a guest complains. Operator precedence is the miswired switch here.

  • Precedence: x & 1 == 0 means x & (1 == 0). Always use parentheses.
  • Negative numbers in Python have infinite leading 1s; mask with 0xFFFFFFFF for 32-bit problems.
  • ~x is -x - 1, not "unsigned flip."
  • x & (x - 1) == 0 is true for 0 too; check x > 0 for power of two.
