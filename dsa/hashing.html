Hash maps and hash sets

The single most useful tool in interviews. A hashmap turns "search the whole array" into one O(1) lookup, and it's the usual way to cut an O(n²) brute force down to O(n).

The idea

A coat check with numbered hooks

A library doesn't search every shelf for a book; the call number tells you exactly which shelf to walk to. A hash function is that call number: it turns any key ("priya", 42, a tuple) into a shelf number. Lookup becomes "compute the shelf, walk straight there," no matter how many books the library holds.

key "cat" ──hash()──▶ 312 ──% 5──▶ bucket 2

bucket 0 │ ·
bucket 1 │ ·
bucket 2 │ "cat"
bucket 3 │ "owl" → "fox"     ← collision: two keys share a bucket
bucket 4 │ "dog"

(toy hash: sum of letter codes; "cat" = 99 + 97 + 116 = 312)

Collisions happen when two keys land in the same bucket. Python's dict handles them by probing for another open slot; the animation shows the simpler "chaining" idea. Either way, a good hash function and automatic resizing keep buckets short, so operations are O(1) on average. The rare worst case (everything colliding) is O(n).

Patterns

Six hashing patterns

1. Seen-before set

O(n) time · O(n) space

A bouncer with a guest list who ticks names off at the door. The second time someone with the same name shows up, the bouncer knows instantly.

Use whendetecting duplicates or cycles (Happy Number: a repeated number means you're in a loop).

def is_happy(n):
    seen = set()
    while n != 1 and n not in seen:
        seen.add(n)
        n = sum(int(d) ** 2 for d in str(n))
    return n == 1

2. Frequency map

O(n)

Writing a ransom note from magazine letters: first count the letters you have, then spend them as you write. If you run out of any letter, you can't finish.

Use whencomparing contents regardless of order.

def can_construct(note, magazine):
    have = Counter(magazine)
    for ch in note:
        if have[ch] == 0: return False
        have[ch] -= 1
    return True

3. Two-way mapping

O(n)

A secret code where each letter always becomes the same symbol, and no two letters share a symbol. You keep a cipher table in both directions to catch either kind of cheating.

Use whenchecking a one-to-one correspondence (Isomorphic Strings, Word Pattern).

def is_isomorphic(s, t):
    a2b, b2a = {}, {}
    for x, y in zip(s, t):
        if a2b.setdefault(x, y) != y or b2a.setdefault(y, x) != x:
            return False
    return True

4. Grouping by a signature

O(n · key cost)

Sorting mail by ZIP code: every letter's ZIP decides its bin, and letters to the same area end up together. The trick is picking a "ZIP code" that's identical for things that belong together.

Use whenitems that are "the same" in some sense must be bucketed (anagrams, shifted strings, same row in Valid Sudoku).

def is_valid_sudoku(board):
    seen = set()
    for r in range(9):
        for c in range(9):
            v = board[r][c]
            if v == '.': continue
            keys = ((v, 'row', r), (v, 'col', c), (v, 'box', r // 3, c // 3))
            if any(k in seen for k in keys): return False
            seen.update(keys)
    return True

5. Prefix sum + hashmap

O(n)

A football match where you want the longest stretch with equal goals for both teams. Track the running score difference. If the difference was +1 at minute 20 and +1 again at minute 70, the goals between minutes 20 and 70 were tied. Remembering the first minute each difference appeared gives the longest stretch.

Use whenlooking for subarrays with a target sum, or balanced counts (Contiguous Array: treat 0 as −1).

def find_max_length(nums):           # equal 0s and 1s
    first = {0: -1}                    # balance → first index seen
    bal = best = 0
    for i, x in enumerate(nums):
        bal += 1 if x else -1
        if bal in first: best = max(best, i - first[bal])
        else: first[bal] = i              # keep the EARLIEST
    return best

6. Hashmap + array for O(1) design

O(1) every operation

A raffle drum with a register. The drum (array) lets you pick a random ticket instantly; the register (hashmap) tells you where any named ticket is so it can be removed instantly, by swapping it with the last ticket and dropping the end.

Use whendesigning a structure with O(1) insert, delete and random/indexed access.

import random
class RandomizedSet:
    def __init__(self): self.vals, self.pos = [], {}
    def insert(self, x):
        if x in self.pos: return False
        self.pos[x] = len(self.vals); self.vals.append(x); return True
    def remove(self, x):
        if x not in self.pos: return False
        i, last = self.pos[x], self.vals[-1]
        self.vals[i], self.pos[last] = last, i       # move last into the hole
        self.vals.pop(); del self.pos[x]; return True
    def getRandom(self): return random.choice(self.vals)

Deep analysis

Find All Anagrams in a String: fixed window + counts

Scanning a long shelf of Scrabble tiles through a 3-tile magnifying window, looking for any arrangement of C-A-T. Slide one tile right: one tile enters, one leaves. You update two counts instead of recounting three tiles each time.

Brute force: for each start, count the window and compare: O(n · m).

Fixed window of length m = len(p). Keep a 26-count array for the window; when sliding, add the new char and remove the old one: O(1) per step.

Comparing two 26-arrays is O(26) = O(1), so the total is O(n).

def find_anagrams(s, p):
    m, res = len(p), []
    need, win = [0] * 26, [0] * 26
    for ch in p: need[ord(ch) - 97] += 1
    for i, ch in enumerate(s):
        win[ord(ch) - 97] += 1
        if i >= m: win[ord(s[i - m]) - 97] -= 1     # leaves the window
        if win == need: res.append(i - m + 1)
    return res

When you hear yourself say "for each element, search for…", ask "could a hashmap answer that search in O(1)?" That question alone solves a large share of Medium problems.

Before you say "done"

Edge cases and pitfalls

A coat check that gives out two identical ticket numbers causes chaos. Make sure your keys really identify what you mean.

  • Using a list as a key: TypeError: unhashable type. Use a tuple.
  • Prefix-sum maps: seed with {0: 1} (counts) or {0: -1} (first index).
  • Storing the latest index when you need the earliest (longest subarray problems).
  • Say "O(1) average" if asked about worst case; mention resizing and collisions.
  • Iteration order: Python dicts keep insertion order, but don't rely on that for correctness unless the problem says so.
