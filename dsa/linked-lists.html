Linked lists

Linked list problems are pointer puzzles. The algorithms are short; the difficulty is not losing a node while you rewire. Draw boxes and arrows every time.

The idea

A treasure hunt of clues

A scavenger hunt: each clue tells you where the next clue is hidden. To reach clue 50 you must follow clues 1 to 49; there's no jumping. But adding a new clue in the middle is easy: rewrite one clue to point to the new spot, and have the new clue point to where the old one used to go. That's a linked list: slow to reach position k, cheap to insert once you're there.

Patterns

Five linked list patterns

1. Dummy (sentinel) node

Removes head special cases

A queue of people where the person at the front might leave. Instead of handling "the first person left" separately, you put a cardboard cutout at the very front. Nobody ever removes the cutout, so the real front is always cutout.next.

Use whenthe head might change: merging, deleting nodes, partitioning.

def merge(a, b):
    dummy = tail = ListNode()
    while a and b:
        if a.val <= b.val: tail.next, a = a, a.next
        else:              tail.next, b = b, b.next
        tail = tail.next
    tail.next = a or b          # attach the leftovers
    return dummy.next

2. Reversal (three pointers)

O(n) time · O(1) space

Turning around a conga line one person at a time. Before you turn someone to face backwards, someone must hold the hand of the next person, or the rest of the line wanders off. That held hand is nxt.

Use whenreversing all or part of a list (Reverse Nodes in k-Group, Reorder List, palindrome check).

def reverse(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next     # 1. save the rest
        cur.next = prev    # 2. flip the arrow
        prev = cur         # 3. step prev forward
        cur = nxt          # 4. step cur forward
    return prev           # new head
before:  None   1 → 2 → 3 → None
step 1:  None ← 1   2 → 3 → None     prev=1 cur=2
step 2:  None ← 1 ← 2   3 → None     prev=2 cur=3
step 3:  None ← 1 ← 2 ← 3            prev=3 cur=None → return 3

3. Fast and slow pointers

O(n) time · O(1) space

Two runners on a track, one twice as fast. On a straight road, when the fast one finishes, the slow one is exactly halfway (find the middle). On a circular track, the fast one eventually laps the slow one (cycle detection).

Use whenfinding the middle, detecting a cycle, or finding where a cycle starts.

def middle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
    return slow

def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast: return True
    return False

Floyd's bonus: after they meet, reset one pointer to head and move both one step at a time. They meet again exactly at the start of the cycle.

4. Gap of n (two pointers, fixed distance)

One pass

Two hikers tied by a 5-metre rope walk a trail. When the front hiker reaches the end, the back hiker is exactly 5 metres from the end. That's how you find the n-th node from the end in one pass.

Use whenthe problem says "k-th from the end."

def remove_nth_from_end(head, n):
    dummy = ListNode(0, head)
    fast = slow = dummy
    for _ in range(n + 1): fast = fast.next   # gap of n+1
    while fast:
        fast, slow = fast.next, slow.next
    slow.next = slow.next.next      # slow is just before the target
    return dummy.next

5. Hashmap old → new (deep copy)

O(n) time · O(n) space

Copying a school's buddy system to a new school. First make a new student for every old student and write down "old Alice → new Alice." Then, for each pair, look up the new versions of their buddies. Copy List with Random Pointer works the same way.

Use whencloning a structure whose pointers can go anywhere.

def copy_random_list(head):
    old2new = {None: None}
    cur = head
    while cur:                         # pass 1: make nodes
        old2new[cur] = Node(cur.val); cur = cur.next
    cur = head
    while cur:                         # pass 2: wire pointers
        old2new[cur].next = old2new[cur.next]
        old2new[cur].random = old2new[cur.random]
        cur = cur.next
    return old2new[head]

Deep analysis

Reorder List: three patterns in one

Shuffling a deck by cutting it in half, flipping the bottom half over, and riffling the two halves together one card at a time.

Turn 1 → 2 → 3 → 4 → 5 into 1 → 5 → 2 → 4 → 3 in O(1) extra space.

Find the middle with fast/slow pointers: node 3.

Cut and reverse the second half: 4 → 5 becomes 5 → 4. Set middle.next = None so the first half ends cleanly.

Merge alternately: 1, 5, 2, 4, 3. Save both next pointers before rewiring each pair.

def reorder(head):
    slow = fast = head
    while fast.next and fast.next.next:
        slow, fast = slow.next, fast.next.next
    second, slow.next = reverse(slow.next), None
    first = head
    while second:
        n1, n2 = first.next, second.next
        first.next, second.next = second, n1
        first, second = n1, n2

Google interviewers like problems that combine patterns. Name each step out loud ("I'll find the middle, reverse the back half, then merge") before writing any code.

Before you say "done"

Edge cases to test

A train conductor checks the engine, the caboose, and a one-car train, because that's where couplings go wrong.

  • Empty list (head is None) and a single node.
  • Two nodes (middle and reversal logic often break here).
  • Removing the head itself, which is why dummy nodes exist.
  • Even vs odd length when finding the middle.
  • Calling .next on None: check fast and fast.next in that order.
