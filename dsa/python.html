The idea

Know your toolbox before the job

A carpenter doesn't build a hammer on the job site. In an interview, writing your own counter or queue costs minutes you need for the actual problem. Knowing that Counter, deque, heapq and bisect exist is like arriving with a full toolbox.

collections

The four you'll use weekly

from collections import Counter, defaultdict, deque, OrderedDict

Counter("banana")              # {'a': 3, 'n': 2, 'b': 1}
Counter(a) == Counter(b)       # anagram check
cnt.most_common(2)             # [('a', 3), ('n', 2)]
cnt["z"]                       # 0, no KeyError

g = defaultdict(list)          # graph / grouping
g[u].append(v)

q = deque([start])             # BFS queue
q.append(x); q.popleft()       # both O(1)
q.appendleft(x); q.pop()       # deque works at both ends

od = OrderedDict()             # LRU cache helper
od.move_to_end(k); od.popitem(last=False)

defaultdict is like a filing cabinet that creates an empty folder the moment you ask for a name that isn't there, instead of telling you "no such folder."

heapq and bisect

Priority queues and sorted lookups

import heapq, bisect
h = []
heapq.heappush(h, (priority, i, item))   # tuples sort by first field, i breaks ties
heapq.heappop(h)                         # smallest
heapq.heapify(lst)                       # O(n)
heapq.heappush(h, -x)                    # max-heap via negation
heapq.nlargest(k, nums, key=f)           # top k

bisect.bisect_left(a, x)                 # first i with a[i] >= x
bisect.bisect_right(a, x)                # first i with a[i] >  x
bisect.insort(a, x)                      # insert keeping order (O(n) shift)
Everyday idioms

Short idioms worth memorizing

# loops
for i, x in enumerate(nums): ...
for a, b in zip(s, t): ...
for i in range(n - 1, -1, -1): ...     # backwards

# sorting
pts.sort(key=lambda p: p[0]**2 + p[1]**2)
words.sort(key=lambda w: (-freq[w], w))  # desc count, then alphabetical

# infinity and grids
INF = float('inf')
grid = [[0] * cols for _ in range(rows)]   # NOT [[0]*cols]*rows
DIRS = ((1, 0), (-1, 0), (0, 1), (0, -1))

# strings
s.isalnum(), s.isdigit(), s.lower(), s.split(), " ".join(words)
ord('a'), chr(97), s[::-1]

# memoization and combinatorics
from functools import cache
from itertools import permutations, combinations, accumulate
list(accumulate([1, 2, 3]))                # [1, 3, 6] prefix sums

# integer math
7 // 2 == 3;  -7 // 2 == -4;  int(-7 / 2) == -3
divmod(17, 5) == (3, 2)
math.gcd(12, 18) == 6;  math.ceil(7 / 2) == 4

Bugs that look like correct code

Google interviews usually use a plain shared document with no autocomplete or run button. Practice typing these idioms without an IDE so they come out right the first time.
