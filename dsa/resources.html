How to use these

A gym membership, not a library card

Owning a gym membership doesn't make you fit; using the machines does. In the same way, watching 50 videos won't prepare you as well as solving the problems yourself. Use videos when you're stuck or after you've tried a problem, then close the tab and write the solution from memory.

WhenUse
Learning a new topicThis guide's page → one explainer video (Abdul Bari, Fiset, ByteByteGo) → a visualizer
Stuck on a problem for 25+ minutesNeetCode's video for that problem, then re-solve it tomorrow without help
System design practiceDesign it yourself first, then compare with Hello Interview, Jordan, or the Primer
Weeks 13–14Mock interviews (Pramp, Interviewing.io, a friend), not new videos
