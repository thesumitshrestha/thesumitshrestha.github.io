Data structures

Stacks and queues

Two simple containers with strict rules about which item leaves next. The monotonic stack built on top of them solves a whole family of "next greater" problems in O(n).

The idea

A stack of plates and a coffee line

Stack (LIFO, last in first out): a stack of plates in a cafeteria. You add to the top and take from the top. The plate washed most recently is used first. Your browser's Back button and your editor's Undo work the same way.

Queue (FIFO, first in first out): the line at a coffee shop. People join at the back and are served from the front, in arrival order. Printer jobs and BFS work the same way.

Patterns

Five stack and queue patterns

1. Matching pairs

O(n) time · O(n) space

Russian nesting dolls. You can only close the doll you opened most recently. If you try to close the big doll while a small one is still open, something's wrong.

Use whenthings open and close in nested order: brackets, HTML tags, function calls.

def is_valid(s):
    pair = {')': '(', ']': '[', '}': '{'}
    st = []
    for ch in s:
        if ch in pair:
            if not st or st.pop() != pair[ch]: return False
        else:
            st.append(ch)
    return not st            # leftovers = unclosed

2. Monotonic stack (next greater element)

O(n) time · O(n) space

People in a line at a parade, all facing the stage. Each person wants to know who is the first taller person in front of them. When a tall person arrives, everyone shorter who was still waiting finally gets their answer and drops out. The waiting group is always sorted tallest-at-the-back, which is why it's called monotonic.

Use whenyou see "next greater/smaller element," "days until warmer," "span," or "largest rectangle."

def daily_temperatures(t):
    ans, st = [0] * len(t), []            # st holds indices still waiting
    for i, x in enumerate(t):
        while st and t[st[-1]] < x:      # x answers everyone cooler
            j = st.pop()
            ans[j] = i - j
        st.append(i)
    return ans

Why O(n) despite the inner while? Each index is pushed once and popped at most once: at most 2n operations in total.

3. Stack that tracks its minimum

O(1) every operation

A climber's logbook where every page records both the current altitude and the lowest point reached so far. Tear off the top page and the page underneath still knows the lowest point as of then.

Use whenyou need min/max of a stack at any moment (Min Stack).

class MinStack:
    def __init__(self): self.st = []          # (value, min so far)
    def push(self, x):
        m = min(x, self.st[-1][1]) if self.st else x
        self.st.append((x, m))
    def pop(self): self.st.pop()
    def top(self): return self.st[-1][0]
    def getMin(self): return self.st[-1][1]

4. Stack for evaluation and decoding

O(n)

A calculator receipt in Reverse Polish Notation: "3 4 + 2 ×". You keep numbers on a pile; each operator takes the top two, combines them, and puts the result back. Decode String does the same with "3[ab]": park what you have, build the inside, then multiply and reattach.

Use whenevaluating expressions, nested repetitions, or simplifying paths.

def eval_rpn(tokens):
    st = []
    for t in tokens:
        if t in "+-*/":
            b, a = st.pop(), st.pop()          # order matters!
            if t == '+': st.append(a + b)
            elif t == '-': st.append(a - b)
            elif t == '*': st.append(a * b)
            else: st.append(int(a / b))     # truncate toward 0
        else:
            st.append(int(t))
    return st[0]

5. Monotonic deque (sliding window max)

O(n) time · O(k) space

Picking the tallest player for each 3-day training camp as players arrive and leave. A newcomer taller than people still in the group makes them irrelevant forever (they'll leave earlier and are shorter), so they're dropped. The tallest is always at the front of the line.

Use whenyou need the max/min of every window of size k.

from collections import deque
def max_sliding_window(nums, k):
    dq, out = deque(), []                 # indices, values decreasing
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x: dq.pop()   # drop the useless
        dq.append(i)
        if dq[0] <= i - k: dq.popleft()            # left the window
        if i >= k - 1: out.append(nums[dq[0]])
    return out
Deep analysis

Largest Rectangle in Histogram

You want to hang the widest possible banner across a row of buildings of different heights. A banner at height h can stretch left and right until it hits a building shorter than h. For each building, find how far the banner at its height can stretch.

For each bar, the best rectangle using its full height spans from the first shorter bar on its left to the first shorter bar on its right. Those are "previous smaller" and "next smaller": a monotonic stack problem.

Keep a stack of indices with increasing heights. When a shorter bar arrives at index i, it is the "next smaller" for every taller bar on the stack. Pop each one; its "previous smaller" is whatever is below it on the stack.

Width = i - stack[-1] - 1 after popping (or i if the stack is empty). Area = height × width.

Append a sentinel height 0 at the end so every bar gets popped and measured.

def largest_rectangle(heights):
    st, best = [], 0
    for i, h in enumerate(heights + [0]):         # sentinel
        while st and heights[st[-1]] > h:
            height = heights[st.pop()]
            width = i if not st else i - st[-1] - 1
            best = max(best, height * width)
        st.append(i)
    return best

Complexity: O(n) time, O(n) space. Brute force (expand from every bar) is O(n²).

If you spot "for each element, find the nearest bigger/smaller one," say "monotonic stack" out loud. It signals pattern fluency, which interviewers note in their write-up.

Before you say "done"

Edge cases to test

A cafeteria worker reaching for a plate on an empty rack: always check the stack isn't empty before you pop or peek.

  • Empty input, and popping from an empty stack.
  • Equal values in monotonic stacks: decide < vs <= deliberately.
  • Leftover items at the end (unclosed brackets, bars never popped).
  • Division in RPN: Python's // floors negatives; use int(a / b) to truncate toward zero.
