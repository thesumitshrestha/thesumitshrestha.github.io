Strings

Strings are arrays of characters with one twist: in Python they can't be changed in place. Most string problems are sliding windows, frequency counts, or palindromes.

The idea

Beads on a string that's been glued shut

A Python string is like a printed name badge. You can read any letter instantly, but you can't change a letter; you print a whole new badge. That's why s += "x" inside a loop is slow: each time, a brand-new badge is printed with every letter copied over.

s = "google"
 index:  0   1   2   3   4   5
        ┌───┬───┬───┬───┬───┬───┐
        │ g │ o │ o │ g │ l │ e │      s[2] → 'o'  (O(1))
        └───┴───┴───┴───┴───┴───┘      s[2] = 'x' → TypeError (immutable)

Rule: to build a string piece by piece, append pieces to a list and call "".join(parts) once at the end. That's O(n) instead of O(n²).

Patterns

Five string patterns

1. Frequency counting

O(n) time · O(k) space, k = alphabet size

Two Scrabble players claim they have the same tiles. Instead of comparing racks letter by letter in order, each tips their tiles into piles by letter and compares pile sizes. Order stops mattering.

Use whenthe problem is about which characters appear and how often: anagrams, permutations of a word, "can I build X from Y."

from collections import Counter
def is_anagram(s, t):
    return Counter(s) == Counter(t)

# Faster with a fixed alphabet: 26 counters
def key(word):
    cnt = [0] * 26
    for ch in word: cnt[ord(ch) - ord('a')] += 1
    return tuple(cnt)          # hashable → Group Anagrams key

2. Variable sliding window

O(n) time · O(k) space

A caterpillar inching along a branch. Its head moves forward to eat; when its body holds something it doesn't want (a repeated leaf), its tail pulls forward until the problem is gone. Head and tail each travel the branch once.

Use whenyou want the longest/shortest contiguous substring meeting a condition.

def longest_unique(s):
    last = {}                 # char -> last index seen
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1    # jump the tail past the repeat
        last[ch] = right
        best = max(best, right - left + 1)
    return best

General template : expand right every step; while the window is invalid, shrink left; record the answer. Minimum Window Substring uses the same skeleton with a "how many characters still needed" counter.

3. Two pointers for palindromes

O(n) time · O(1) space

Checking a folded paper cut-out: you look at the two outer edges, then the next two in, and so on. If every matching pair agrees, the shape is symmetric.

Use whenchecking whether a string reads the same both ways, often while skipping punctuation.

def is_pal(s):
    l, r = 0, len(s) - 1
    while l < r:
        while l < r and not s[l].isalnum(): l += 1
        while l < r and not s[r].isalnum(): r -= 1
        if s[l].lower() != s[r].lower(): return False
        l, r = l + 1, r - 1
    return True

4. Expand around center

O(n²) time · O(1) space

Dropping a pebble in a pond: ripples spread out evenly from the center. Every palindrome has a center, so drop a pebble at each position (and between each pair of letters) and let it spread while both sides match.

Use whenfinding or counting palindromic substrings.

def longest_pal(s):
    best = ""
    def grow(l, r):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l, r = l - 1, r + 1
        return s[l + 1:r]
    for i in range(len(s)):
        for cand in (grow(i, i), grow(i, i + 1)):   # odd, even
            if len(cand) > len(best): best = cand
    return best

Forgetting the even-length center (i, i + 1) misses palindromes like "abba". Manacher's algorithm does this in O(n), but it's rarely expected.

5. Careful parsing

O(n)

A bank teller reading a handwritten cheque amount: skip the leading spaces, note a minus sign, read digits until something that isn't a digit, and refuse anything larger than the account limit. String to Integer (atoi) is exactly this.

Use whenthe problem is mostly about handling messy input step by step.

def atoi(s):
    i, n, sign, num = 0, len(s), 1, 0
    while i < n and s[i] == ' ': i += 1
    if i < n and s[i] in '+-':
        sign = -1 if s[i] == '-' else 1; i += 1
    while i < n and s[i].isdigit():
        num = num * 10 + int(s[i]); i += 1
    return max(-2**31, min(2**31 - 1, sign * num))

On parsing problems, list the cases out loud before coding (spaces, sign, junk after digits, overflow). Interviewers grade the questions you ask as much as the code.

Deep analysis

Minimum Window Substring, step by step

You're shopping with a list: 1 apple, 1 banana, 1 cherry. You walk down a long market aisle grabbing stalls into your basket. As soon as the basket covers the list, you try dropping stalls from the back of the line to see how short your trip could be, then keep walking to look for an even shorter trip.

Find the smallest window of s containing every character of t (with counts).

Count what you need: need = Counter(t), and missing = len(t).

Move right forward. If need[ch] > 0, this character was still missing, so missing -= 1. Always do need[ch] -= 1 (negative means a spare).

When missing == 0, the window is valid. Shrink from the left while the leftmost char is a spare (need[s[left]] < 0), restoring its count.

Record the window if it's the shortest. Then give up the leftmost character on purpose (need[...] += 1; missing += 1; left += 1) and keep scanning.

from collections import Counter
def min_window(s, t):
    need, missing = Counter(t), len(t)
    left, best = 0, (0, float('inf'))
    for right, ch in enumerate(s):
        if need[ch] > 0: missing -= 1
        need[ch] -= 1
        if missing == 0:
            while need[s[left]] < 0:        # drop spares
                need[s[left]] += 1; left += 1
            if right - left < best[1] - best[0]:
                best = (left, right)
            need[s[left]] += 1; missing += 1; left += 1
    return "" if best[1] == float('inf') else s[best[0]:best[1] + 1]

Complexity: each pointer moves at most n times, so O(n + m) time and O(k) space for the counter.

Before you say "done"

Edge cases to test

Like a form validator on a sign-up page, test the inputs real users actually type: blank, one letter, spaces, capitals, and emoji.

  • Empty string and single character.
  • Upper vs lower case (ask whether "A" equals "a").
  • Spaces and punctuation (Valid Palindrome ignores them).
  • Only lowercase a–z, or any Unicode? This decides whether a 26-slot array works.
  • All characters identical ("aaaa") for window problems.
