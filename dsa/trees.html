Trees and tries

Trees are one of Google's favorite topics. Nearly every tree problem is a DFS where you decide what each node returns to its parent, or a BFS by levels.

The idea

A family tree, upside down

A company org chart. The CEO is the root; each manager has direct reports (children); people with no reports are leaves. To ask "how many people are in Engineering?", you ask the head of Engineering, who asks each of their managers, who ask theirs, and the answers add up on the way back. That bottom-up reporting is recursion on a tree.

            8          ← root          depth 0
          /   \
         3     10                      depth 1
        / \      \
       1   6      14                   depth 2
          / \    /
         4   7  13     ← leaves        depth 3      height = 3
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val, self.left, self.right = val, left, right

This particular tree is a binary search tree (BST): everything in a node's left subtree is smaller, everything on the right is larger. That rule makes search O(height), which is O(log n) if the tree is balanced and O(n) if it degrades into a line.

Reading a book: preorder is reading each chapter title before its sections (a table of contents). Postorder is a manager who only reports a total after every team has reported (computing folder sizes on your disk). Level order is a seating chart, row by row.

Patterns

Six tree patterns

1. DFS that returns a value (bottom-up)

O(n) time · O(h) stack

A building's fire warden asks each floor warden "how many people on your floor and above?" Each floor asks the floor above, adds its own count, and reports down. The question is the same at every level; only the numbers change.

Use whenthe answer for a node depends on answers from its children: height, size, balanced?, diameter, max path sum.

def max_depth(root):
    if not root: return 0                      # base case
    return 1 + max(max_depth(root.left), max_depth(root.right))

The recipe: (1) what does an empty tree return? (2) what does this node return, given its children's returns? Answer those two questions and the code writes itself.

2. DFS with a global answer

O(n)

Each regional office reports its best single-region sales number upward, but head office also tracks a separate leaderboard for the best combined deal between two regions. What a node returns and what it records are different things.

Use whenthe best answer may "bend" through a node (diameter, max path sum) but a parent can only extend one straight branch.

def diameter(root):
    best = 0
    def depth(node):
        nonlocal best
        if not node: return 0
        l, r = depth(node.left), depth(node.right)
        best = max(best, l + r)        # path bending here
        return 1 + max(l, r)           # straight branch for the parent
    depth(root)
    return best

3. BFS level by level

O(n) time · O(width) space

Ripples from a stone: everything one ring out is reached before anything two rings out. A queue holds the current ring; you finish it before starting the next.

Use whenoutput is grouped by level, or you need the shallowest/closest node.

from collections import deque
def level_order(root):
    if not root: return []
    out, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):          # exactly this level's nodes
            node = q.popleft()
            level.append(node.val)
            if node.left:  q.append(node.left)
            if node.right: q.append(node.right)
        out.append(level)
    return out

4. BST range checking (top-down)

O(n)

A house-hunting filter: "price between $300k and $500k." Going left in a BST tightens the maximum; going right tightens the minimum. Each node is checked against the allowed range it inherited from all its ancestors, not just its parent.

Use whenvalidating a BST, or any time constraints flow down from ancestors.

def is_valid_bst(node, lo=float('-inf'), hi=float('inf')):
    if not node: return True
    if not (lo < node.val < hi): return False
    return (is_valid_bst(node.left, lo, node.val) and
            is_valid_bst(node.right, node.val, hi))

The classic bug: only comparing a node with its parent. A 4 in the right subtree of 5's left child can still violate the root.

5. Lowest common ancestor

O(h) in a BST · O(n) in a general tree

Two cousins want their closest shared ancestor. Each walks up the family tree; the first person who appears on both paths is the answer. In a BST it's simpler: start at the root and walk toward both; the node where they'd split directions is the LCA.

Use whenasked for the meeting point of two nodes.

def lca_bst(root, p, q):
    while root:
        if p.val < root.val and q.val < root.val: root = root.left
        elif p.val > root.val and q.val > root.val: root = root.right
        else: return root                 # they split here

def lca(root, p, q):                          # any binary tree
    if not root or root is p or root is q: return root
    l, r = lca(root.left, p, q), lca(root.right, p, q)
    return root if l and r else l or r

6. Trie (prefix tree)

O(L) per word, L = word length

Your phone's keyboard autocomplete. After you type "goo", it walks g → o → o in a tree of letters and suggests everything below that point: "good", "google", "goose". Words that share a prefix share the same path, so the prefix is stored once.

Use whenthe problem says prefix, autocomplete, dictionary of words, or searching many words in a grid (Word Search II).

class Trie:
    def __init__(self):
        self.root = {}
    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node['$'] = True                     # end-of-word marker
    def _walk(self, s):
        node = self.root
        for ch in s:
            if ch not in node: return None
            node = node[ch]
        return node
    def search(self, word):
        node = self._walk(word); return bool(node) and '$' in node
    def startsWith(self, prefix):
        return self._walk(prefix) is not None
Deep analysis

Binary Tree Maximum Path Sum

A hiker plans a route across a mountain range where each peak gives or costs energy. The route can go up one side of a peak and down the other, but it can't branch. Bad sections (negative values) are simply skipped by starting or ending the route elsewhere.

At each node, ask each child for the best straight path going down from it. If that's negative, use 0 (don't take that branch).

A path that bends at this node is worth node.val + left + right. Compare it with the global best.

Return to the parent only node.val + max(left, right), because the parent can extend just one branch.

def max_path_sum(root):
    best = float('-inf')
    def gain(node):
        nonlocal best
        if not node: return 0
        l = max(gain(node.left), 0)
        r = max(gain(node.right), 0)
        best = max(best, node.val + l + r)
        return node.val + max(l, r)
    gain(root)
    return best

Complexity: O(n) time, O(h) space for recursion. Start best at negative infinity, not 0, so an all-negative tree returns its largest single value.

When a tree problem stumps you, ask: "What should each node return to its parent, and is the final answer the same thing or something different?" If different, you need a global variable like best.

Construction

Building a tree from preorder + inorder

Rebuilding a seating plan from two lists: the order guests arrived (preorder tells you who's the head of each table first) and their left-to-right seat order (inorder tells you who sits left vs right of that head).

Preorder's first value is the root. Find it in inorder: everything left of it is the left subtree, everything right is the right subtree. Recurse. Use a value → index map so each lookup is O(1), making the whole build O(n).

def build(preorder, inorder):
    idx = {v: i for i, v in enumerate(inorder)}
    it = iter(preorder)
    def go(lo, hi):
        if lo > hi: return None
        val = next(it)
        node = TreeNode(val)
        node.left = go(lo, idx[val] - 1)
        node.right = go(idx[val] + 1, hi)
        return node
    return go(0, len(inorder) - 1)
Before you say "done"

Edge cases to test

An org chart with only the CEO, or one where everyone reports in a single chain, breaks more reporting tools than a normal company does.

  • Empty tree (root is None) and a single node.
  • A skewed tree (a straight line): height = n, recursion depth = n. Python's default limit is 1,000.
  • Negative values (max path sum).
  • Duplicate values in a BST: ask whether they go left, right, or are disallowed.
