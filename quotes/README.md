# unsaid — quote image maker for @unsaid.daily

Type a quote, pick a style (sticky note, copy paper, photo, phone notes), and save the image for Instagram or TikTok.

## Put it on GitHub Pages
1. Create a new public repository on github.com (for example `unsaid`).
2. Click **Add file → Upload files** and drag in everything from this folder: `index.html`, `README.md` and the whole `photos` folder.
3. Click **Commit changes**.
4. Go to **Settings → Pages**. Under "Branch" choose `main` and `/ (root)`, then **Save**.
5. After a minute your site is live at `https://YOUR-USERNAME.github.io/unsaid/`.

## Notes
- Captions and photo suggestions use simple built-in templates here (the Claude-written versions only work inside Claude).
- On iPhone, **Save image** opens the share sheet: choose "Save Image" to put it in Photos.
- Library photos are Pixabay-licensed images (via github.com/yavuzceliker/sample-images), free to use.
